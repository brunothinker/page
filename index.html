Download (.deb) package

Option 1: Graphical Software Center

  1. Download the .deb package using the button above.
  2. Open your file manager, navigate to Downloads, and double-click fallbyte_2.1.0_amd64.deb.
  3. Your system's Software Center (App Center / GDebi) will open automatically — click Install and enter your password.

Option 2: Terminal (Download & Install)

sudo apt update && sudo apt install -y curl
curl -fL https://github.com/brunothinker/FallByte/releases/download/v2.1.0/fallbyte_2.1.0_amd64.deb -o /tmp/fallbyte_2.1.0_amd64.deb
sudo apt install -y /tmp/fallbyte_2.1.0_amd64.deb && rm -f /tmp/fallbyte_2.1.0_amd64.deb
Download (.rpm) package

Option 1: Graphical Software Center

  1. Download the .rpm package using the button above.
  2. Open Files, go to Downloads, and double-click fallbyte_2.1.0_x86_64.rpm.
  3. GNOME Software / KDE Discover will open the package page — click Install to complete setup.

Option 2: Terminal (Download & Install)

sudo dnf check-update; sudo dnf install -y curl
curl -fL https://github.com/brunothinker/FallByte/releases/download/v2.1.0/fallbyte_2.1.0_x86_64.rpm -o /tmp/fallbyte_2.1.0_x86_64.rpm
sudo dnf install -y /tmp/fallbyte_2.1.0_x86_64.rpm && rm -f /tmp/fallbyte_2.1.0_x86_64.rpm
Download (.AppImage) binary

Option 1: File Manager (No Installation Needed)

  1. Download fallbyte_2.1.0_x86_64.AppImage.
  2. Right-click the file → Properties → Permissions and enable Allow executing file as program.
  3. Double-click the AppImage file to run FallByte immediately.

Option 2: Terminal (Download & Run)

# Make sure curl is installed (e.g., sudo pacman -Syu --needed curl)
curl -fLO https://github.com/brunothinker/FallByte/releases/download/v2.1.0/fallbyte_2.1.0_x86_64.AppImage
chmod +x fallbyte_2.1.0_x86_64.AppImage
./fallbyte_2.1.0_x86_64.AppImage
Download for Windows

Quick Installation

  1. Download and double-click fallbyte_2.1.0_x64_installer.exe to launch the setup wizard.
  2. Follow the on-screen prompts to finish installing FallByte.
Windows Smart App Control & SmartScreen Notice

Because FallByte is a free, independent open-source project without a paid commercial EV Code-Signing certificate, Windows 11's Smart App Control may block the installer from running (or SmartScreen may show "Windows protected your PC").

To proceed: if SmartScreen appears, click More info → Run anyway. If Smart App Control blocks it on Windows 11, open Smart App Control settings using the shortcut below and switch it to Off.
